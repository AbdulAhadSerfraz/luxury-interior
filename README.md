# Luxury Interior — Hero Section

A modern, elegant hero section for a luxury interior design website. Built with pure HTML and CSS, featuring a custom font, full-width hero image, and a beautiful call-to-action button.

---

<img width="1352" height="610" alt="luxury hero secreenshot" src="https://github.com/user-attachments/assets/b02836b7-82e4-4f01-a1ef-7394aae78fdd" />

## ✨ Features

- 🖼️ Full-width hero image with rounded corners
- 🔤 Custom font (`EROSYRegular`) loaded via `@font-face`
- 📝 Centered headline and subtitle over the image
- 🎨 Elegant pill-shaped button with smooth hover animation
- 📱 Fully responsive layout
- 🎯 Clean, minimal, luxury-brand aesthetic

---

## 🛠️ Built With

- **HTML5** — Structure
- **CSS3** — Styling, layout, and animations
- **Custom font** — `EROSYRegular.otf`
